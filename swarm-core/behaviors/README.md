# Swarm Agent Behaviors

This directory contains the runtime behavior definitions and specialized instructions for each agent in the swarm. These behaviors complement the identity and structural definitions found in `swarm/core/agents/`.

## Manifest

| Behavior | Description |
| :--- | :--- |
| [coder.md](coder.md) | Senior engineer who writes production-quality code, implements, debugs, and tests. |
| [contract-critic.md](contract-critic.md) | API Designer + Interface Pedant focused on naming, symmetry, and error contracts. |
| [failure-dramatist.md](failure-dramatist.md) | Chaos Engineer who narrates failure modes as concrete scenarios to make edge cases visceral. |
| [friction-auditor.md](friction-auditor.md) | UX Flow Analyst identifying where users get stuck, confused, or frustrated across all interfaces. |
| [marketplace-memory.md](marketplace-memory.md) | Domain-specific memory and context for the Inditex Marketplaces IOP ecosystem. |
| [memory-curator.md](memory-curator.md) | Librarian of the swarm managing compaction, pruning, and cross-pollination of learnings. |
| [personal-assistant.md](personal-assistant.md) | Executive assistant managing tasks, reminders, and personal context. |
| [planner.md](planner.md) | Orchestrator responsible for goal decomposition, pipeline selection, and coordination. |
| [product-owner.md](product-owner.md) | Product strategist validating that plans deliver real user value and align with scope. |
| [qa-guardian.md](qa-guardian.md) | QA Lead checking for quality gaps, security vulnerabilities, and standards compliance. |
| [researcher.md](researcher.md) | Staff engineer performing technical spikes, investigating deeply, and synthesizing findings. |
| [retrospective.md](retrospective.md) | Process improver analyzing execution history to find patterns and friction. |
| [reviewer.md](reviewer.md) | Senior peer reviewer catching issues before they ship through functional and technical review. |
| [security-sentinel.md](security-sentinel.md) | SOC analyst and CISO with the privilege to halt execution for security reasons. |
| [spec-writer.md](spec-writer.md) | Product-technical writer bridging vision and execution through structured specs and stories. |
