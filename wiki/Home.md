# Welcome to OSS-Swarm

**OSS-Swarm (PersonalAgent Swarm v2)** is a portable, multi-agent swarm system designed for software engineering. 

It features 6 core agents, behavioral mode overlays, self-improvement with strict guardrails, and external package support.

## Why OSS-Swarm?

Unlike rigid, monolithic AI coding assistants, OSS-Swarm offers:
- **Strict Decoupling**: The cognitive orchestration (Portable Core) is completely separated from the execution backend (Runtime Adapter).
- **Agent Consolidation**: Instead of endless agent sprawl, we use 6 foundational agents and apply dynamic "Modes" (like Security or Architecture lenses).
- **Sandboxed Self-Improvement**: The swarm can improve its memory and policies, but destructive actions and core invariants are strictly guarded by human approvals.
- **True Portability**: Run it on OpenCode or Antigravity simply by swapping the adapter.
